https://dataspace.copernicus.eu/

## Processing
- Coordinate reference system will be recorded for every dataset.
- Area calculations will use a projected CRS.
- Raw satellite data will not be committed to Git.
- Processed evidence layers will be stored in data/outputs/.
- Original data sources and acquisition dates will be recorded here.
